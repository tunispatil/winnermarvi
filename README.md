## Project I'm most focused on
 
**[Auto Data Storyteller / AI Business Analyst](https://github.com/winnermarvi/AUTO-DATA-STORYTELLER)**
 
Takes a CSV, runs EDA, trains and picks the best ML model, and lets you chat with the
results using RAG instead of just prompting an LLM with the raw data. Also generates a PDF
report at the end.
 
FastAPI backend, Streamlit frontend, FAISS + Sentence-Transformers for retrieval, Llama 3
through Groq.
 
[Demo video](https://youtu.be/3ayy6pWXqNM)
